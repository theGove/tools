# How to create a new availabook

1. create a new blog in blogger call Book1XXX (the x's are numbers)
2. copy the theam from book1011 into the new book
3. copy all the posts from book1011 into the new book
4. just so you know, bloger will create the permanant name of the html file for a the blob post, the first time you create the post. so for book chapters, first name the post the chapter number, such as "5".
5. we need to do something similar for the post created date. when you first create the post, the year MUST be 2000, and the month MUST be Feb, the time does not mater.
6. once you have create the new post, go back and change the name to something like "5. <chapter name>" and change the post date to the correct one.
7. if you did this correctly, the final path for the post will be 2000/02/5.html having this pattern is important for availabooks to work correctly.
